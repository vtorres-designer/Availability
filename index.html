Edit your calendar

Your calendar is saved in your GitHub repository. To edit it from this phone or computer, paste a GitHub key once. It stays on this device only.

  1. Open GitHub → New fine-grained token.
  2. Name it Availability calendar. Pick the longest expiration offered.
  3. Repository access: Only select repositories → availability.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Tap Generate token, copy it, and paste it below.
